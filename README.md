# MnemosyneC Releases

Signed installer downloads for **MnemosyneC**, the cooperative substrate desktop application.

This repository exists **only to host release artifacts**. It contains no source code and
no development history. Source lives in a separate private repository.

## Downloads

Installers are attached to the [Releases](../../releases) page, not committed to this
repository. Each release lists a SHA-256 for the installer; verify it before running.

Windows:

    Get-FileHash .\MnemosyneC-Setup-<version>.exe -Algorithm SHA256

## Verifying a download

The authoritative SHA-256 for each release is published in that release's notes and in
`checksums.txt` on this repository. If a downloaded file's hash does not match, do not
run it.
